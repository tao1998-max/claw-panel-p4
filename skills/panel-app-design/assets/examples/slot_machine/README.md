# 霓虹老虎机 (Neon Slot Machine)

3×3 classic slot machine as a launcher App. Pure Lua: one `image.new` canvas
redrawn per frame and handed to LVGL with `set_frame`, a 30-50 fps game loop on
`lvgl.process_events(20)`, and no firmware changes.

- **Reels**: each column is a shuffled 24-symbol strip; symbols are 128×128
  JPEG icons `blit`-ed onto the canvas (4 rows drawn per column so the
  scrolling gap never shows). Spin eases in to 24 sym/s; each reel decelerates
  with easeOutCubic onto a random target. Tapping a reel column while it
  spins stops that reel early.
- **Payouts**: 3 rows + 2 diagonals; 3-of-a-kind pays `bet × symbol` (7 = 50,
  BAR = 20, diamond = 12, coin = 8, star = 5, cherry = 3), any pair on a line
  returns the bet. 777 is a jackpot.
- **Juice**: OGG sfx (`assets/sfx/*`, generated by `tools/gen_assets.py`),
  gold-coin particles on the canvas, a win banner, and
  `claw.speak_async("恭喜中奖 N 金币")` — the fire-and-forget TTS added in
  firmware seed 47, so the game loop never blocks on speech. 语音/音效 can be
  toggled off; 自动 spins continuously.
- **Persistence**: balance/best/settings saved to `slot_save.json` in the
  workspace (`claw.file` + `claw.json`). Running out of coins gifts 100.
- **Fonts**: `assets/ui_cn.ttf` is a small subset generated by
  `make_cjk_subset.py --source-font <full font> --lua scripts/main.lua`.

Regenerate assets (symbols, icon, sfx) with
`python tools/gen_assets.py` (needs Pillow + ffmpeg on PATH).

Techniques demonstrated: canvas game loop with `set_frame`, `blit` sprite
reels, per-frame C-side drawing (~30 primitives/frame), particle effects,
`lvgl.process_events` pacing, cooperative exit, TTF subset workflow, and
`claw.speak_async` for non-blocking voice feedback.
